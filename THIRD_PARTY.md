# Third-party material

BearVision depends on third-party Python packages declared in `pyproject.toml`.
Those packages remain subject to their own licences.

The BearVision source-code licence has not yet been selected. This is an owner
decision and must be resolved before public or commercial distribution.

Large YOLO ONNX weights and test videos are stored through Git LFS. Their
presence in this repository does not change the upstream model or media licence.
Before a public or commercial release, verify and record the provenance and
redistribution terms for every model and test video.

The former vendored KBeacon Android/Java SDK has been removed from active source
and placed in the separately generated local archive ZIP. It is not distributed
as part of the BearVision 3 Python package.
